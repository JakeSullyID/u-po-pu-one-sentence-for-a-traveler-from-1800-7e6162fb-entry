# One Sentence for a Traveler from 1800

This entry is a self-contained Node 22 program that deterministically writes a single concise sentence explaining the modern internet to a traveler from 1800 into `entry.txt`, operating entirely offline with zero external dependencies. Presenting a single coherent mental image succeeds where feature lists fail because historical intuition instantly grasps a unified metaphor without drowning in modern technical jargon.

## How to Run

Execute the program using Node 22:

\`\`\`bash
node main.ts
\`\`\`

You can specify a custom output directory by setting the `MAKEFUN_OUTPUT_DIR` environment variable:

\`\`\`bash
MAKEFUN_OUTPUT_DIR=./dist node main.ts
\`\`\`
